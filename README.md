
# Ashwanth A - Personal Portfolio

A responsive personal portfolio website built using HTML, CSS, and JavaScript.

## Features

- Center-aligned hero / first page
- No profile photo
- About section
- Technical skills
- Projects showcase
- Education details
- Separate Certifications and Achievements sections
- Responsive mobile navigation
- Dark and light theme toggle
- Typing animation
- Back-to-top button
- Email, GitHub, and LinkedIn links

## Technologies Used

- HTML5
- CSS3
- JavaScript

## Project Structure

```text
portfolio/
├── index.html
├── style.css
├── script.js
└── README.md
```

## How to Run

1. Download or copy all four files into one folder.
2. Open the folder in Visual Studio Code, if available.
3. Open `index.html` in a web browser.
4. Edit `index.html` to change content.
5. Edit `style.css` to change the design.
6. Edit `script.js` to change interactive features.

No build tools or package installation are required.
